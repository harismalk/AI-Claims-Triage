# Resolution letter quality rubric

Score each letter 1-5. A letter satisfying all five dimensions below is a 5;
each missing or violated dimension costs at least a point. Use judgment for
problems these dimensions don't name outright (an unprofessional or dismissive
tone, for instance, can sink a letter's score even if every dimension below
is technically present).

1. **Greeting** -- opens by addressing the member by name ("Dear {name},").
2. **Clear decision** -- states plainly whether a payment is being issued or
   the original decision is upheld. A reader should not have to guess.
3. **Amount stated correctly** -- if a payment is being issued, states the
   exact dollar amount; if the decision is upheld, does not invent one.
4. **Plain-language reason, no jargon** -- gives the reason in plain English.
   Never a bare internal code (`DUP`/`BIL`/`DOC`/`COV`), a claim ID, a plan
   code, or a procedure code. A jargon leak is a serious defect, not a minor
   one -- a member should never see the inside of the claims system.
5. **Professional closing** -- ends with a closing and signature (e.g.
   "Sincerely, Member Services") and invites further questions.

Score 1: a majority of dimensions missing, or the letter is unintelligible or
inappropriate for a member to receive regardless of which boxes it checks.
